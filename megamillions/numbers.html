Mega Millions number statistics

Mega Millions number pages on LotteryMigo are counts from the NY Open Data archive, split so the current matrix is not averaged together with retired ones. The white-ball table below uses 939 drawings from October 31, 2017 through October 27, 2026. The even-split column is the count each number would have if those drawings had been shared perfectly evenly: 939 drawings times 5, divided by 70.

The gap column is how many drawings have passed since the number last appeared in that same set. A gap of zero means the number was in the latest drawing. A long gap is a fact about the list. It does not raise the chance that the number is drawn next. White balls are still 5 out of 70 on the next drawing. Read the hot, cold, and overdue guide before treating a rank as a tip, and the rules guide for the prize chart behind the odds.

The five longest current white-ball gaps in this set are white ball 69 (56 drawings since April 14, 2026), white ball 52 (35 drawings since June 26, 2026), white ball 39 (31 drawings since July 10, 2026), white ball 44 (27 drawings since July 24, 2026), white ball 18 (25 drawings since July 31, 2026). They are listed so you can open the draw dates, not so you can treat them as due.
